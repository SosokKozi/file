# Осколки скорости

3D-раннер в духе HASTE: Broken Worlds. Он написан на Three.js и умещается в один файл `index.html`, сборка не нужна.

Чтобы поиграть, откройте `index.html` в браузере (Three.js загружается с jsDelivr).

## Управление

| Клавиши | Действие |
|---|---|
| A / D, ← → | движение в стороны |
| Пробел, W, ↑ | прыжок; в воздухе — двойной прыжок с сальто (с A/D — боковое сальто) |
| Shift, S, ↓ | кувырок; в воздухе — резкое падение |
| Shift прямо перед землёй | идеальное приземление: ускорение и кувырок |
| Esc / P, R, M | пауза, заново, звук |

На телефоне управление идёт экранными кнопками.

## Миры

1. Рассветные осколки — обучение: пропасти, стены, балки, обрывы, батут, шипы, ускорители.
2. Янтарная пустошь — колонны, рассыпающиеся плиты, движущиеся блоки.
3. Багровый разлом — вращающиеся балки и лазеры.
4. Ледяные шпили — узкие балки, движущиеся платформы, ступени.
5. Сердце бури — смесь всех препятствий.

Ранг (S/A/B/C) зависит от времени и числа падений. Прогресс сохраняется в браузере.
