# Проверка

## Перед каждым коммитом (любая машина, даже без Unity)

```bash
dotnet test tools/SimTests                        # 40+ тестов Sim
dotnet build tools/CompileCheck                   # Game + Editor компилируются (старый ввод)
dotnet build tools/CompileCheck -p:NewInput=true  # ветка Input System
```

Оба должны быть зелёными. Нет .NET 8 — `apt-get install dotnet-sdk-8.0` или установщик с dot.net.

## Что покрыто тестами

| Тест | Ловит |
|---|---|
| `DungeonGenTests.ManySeeds_AllValid` | недостижимый босс, отрезанный пол, маленькая арена — 300 seed × каждая зона |
| `SameSeed_SameLayout` | недетерминизм генерации |
| `Prologue_HasFewEnemies_AndNoElites` | пролог стал перегруженным |
| `ItemTests` | неверные свойства, ярусы, редкость, уникальные, лут босса |
| `HeroAndQuestTests` | уровни, навыки, экипировка, задания, торговля, формулы урона |
| `AssetCatalogTests` | модель без записи в каталоге |

Новая механика в Sim = новый тест. Тесты лежат в `Assets/_Project/Tests/EditMode` и работают и в .NET, и в Unity Test Runner.

## В редакторе (через Unity MCP, см. `unity-mcp-workflow`)

1. Консоль без ошибок после импорта.
2. EditMode-тесты зелёные.
3. Смоук: Play → «Новая игра» → 30 с → консоль без исключений → Stop.

## Ручной чек-лист прохождения (≈15 минут)

- [ ] Титул: «Новая игра» запускает пролог, «Продолжить» неактивна без сохранения.
- [ ] Пролог тёмный, фонарь вокруг героини, 3–15 врагов, подсказка управления внизу.
- [ ] Мазок бьёт дугой, числа урона, враги лопаются краской, кляксы на полу.
- [ ] Каждый удар врага предупреждён кругом/полосой; от удара можно уйти.
- [ ] На 2 уровне появляются «Брызги» в ПКМ, сообщение о навыке.
- [ ] Серый Глашатай: полоса здоровья, удар по площади, залп, призыв на 70%/35%.
- [ ] После победы: «Задание выполнено», портал → лагерь.
- [ ] Лагерь: светло, 4 NPC, Пробел — разговор; Гуашь даёт «Цвет из тины».
- [ ] Сангина и Индиго торгуют; продажа из сумки, покупка, зелья.
- [ ] Мольберт: открыты только доступные зоны; каждый заход — новая карта.
- [ ] Сумка: надеть/снять, требования уровня, подсказка с характеристиками.
- [ ] Смерть → «Вернуться в лагерь»; пауза → сохранить → меню → «Продолжить».

## Производительность

Profiler в самой плотной зоне (катакомбы, бой с 20+ врагами): ≤ 16.6 мс CPU на ПК средней руки; draw calls — болванки дают много, это ожидаемо до замены моделей. Регрессия ≥ 20% — разбираться до коммита.
