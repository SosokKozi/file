# Персонажи и анимация

## Героиня — Мирра

Молодая художница: красный берет, рыжий хвост, фиолетовое пальто, кремовый фартук в пятнах краски, кисть почти в её рост. Рост 1.8 м, голова крупная (мультяшно). Кончик кисти меняет цвет на пигмент последнего навыка — главный индикатор «чем я сейчас бью».

## Договорённость о моделях (для болванок, Blender и Tripo)

| Правило | Значение |
|---|---|
| Единицы | 1 = 1 м; героиня 1.8, NPC ~2, мелкие враги 0.9–1.8, боссы 3.5–6 |
| Ось | смотрит по +Z Unity (в Blender: −Y, «вид спереди») |
| Начало координат | между ступнями, на полу |
| Узлы | `Body` — всё тело (качание/сплющивание); `BrushPivot` — точка в правой руке; `BrushTip` — кончик кисти с отдельным материалом |
| Поиск узлов | `AssetProvider.FindDeep` — глубина вложенности не важна |

Нет узла — анимация этого узла просто пропускается (ошибок не будет).

## Анимация сейчас (процедурная, `Hero.Animate`, `Enemy.Animate`)

- Бег: подпрыгивание `Body` ±8 см, наклон вперёд 8°.
- Взмах: `BrushPivot` описывает дугу 140° за 0.2 с, направление чередуется.
- Удар по героине: крен тела. Смерть: тело скрывается в взрыве краски.
- Враги: подпрыгивание при беге, «сплющивание» при попадании (`punch`), замах — раздувание и откидывание назад.

## Переход на скелет

1. Рига: Humanoid (Mixamo-совместимые имена костей) для героини и NPC; Generic для существ.
2. Клипы героини: Idle, Run, Cast_Swing_L/R, Cast_Overhead (взрывы), Cast_Throw (брызги), Dash, Hit, Death, Victory.
3. Animator: слой ног (Idle/Run по скорости), верхний слой с маской (касты), триггеры из `Hero.Swing`/`StartDash`.
4. События анимации «Release» — момент нанесения урона. До этого урон наносится сразу при касте (ощущается отзывчиво — сохраните: окно замаха ≤ 0.12 с).
5. Кисть — отдельный меш, прикреплённый к кости руки (`BrushPivot` = дочерний узел кости).

## Враги и боссы

Силуэт важнее деталей: горбатый (Выцветший), шар с трубой (Плевун), ящик с бивнями (Таран), колючая клякса, волк-набросок, рыцарь-ластик. Боссы — увеличенный вариант + корона/отличительный элемент + свой цвет глаз. Каждый босс ≥ 2× выше героини.

## Облики (дальше)

Облики героини и кисти — только внешний вид, без характеристик: `SkinDef { id, assetId, brushTipOverride }`, хранение в `GameState`.
