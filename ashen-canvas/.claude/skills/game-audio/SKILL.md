# Звук и музыка

## Звуковая идея

Мир глухой и выцветший — тишина, ветер, капли, далёкий колокол. Героиня — сочная: влажные шлепки, брызги, «бульк» краски, звонкие взрывы. Чем больше краски на экране, тем богаче звук.

## Архитектура (план)

- `AudioMixer`: Master → Music, Ambience, SFX (→ SFX_Hero, SFX_Enemy), UI. Громкости групп — в настройках, хранить в `PlayerPrefs` (не в `GameState`).
- `Game/Audio/Sfx.cs`: пул из 24 `AudioSource`, `Sfx.Play(id, pos, pitchJitter)`. Вызывать рядом с вызовами `FxSystem` — одно событие = эффект + звук.
- Данные: `SoundDef` (ScriptableObject): клипы-варианты, громкость, разброс тона ±5–10%, лимит одновременных (5 одинаковых — больше не играть).
- Музыка: `MusicDirector` — трек зоны с двумя слоями (исследование / бой: включается при агрессии врагов рядом), кроссфейд 1.5 с; у боссов свой трек.

## Список звуков первой очереди

| Событие | Звук |
|---|---|
| Мазок | взмах + шлепок краски |
| Брызги | три «пчх», лопание капель |
| Лазурная волна | плеск воды + хрусталь |
| Росчерк | свист + размазывание |
| Золотой взрыв | треск заряда → звонкий взрыв |
| Чернильный разлив | бульканье, шипение тика |
| Шедевр | аккорд + серия взрывов |
| Попадание по врагу | глухой тычок; крит — звонче |
| Смерть врага | «пуф» + брызги (тон по размеру) |
| Предупреждение врага | короткий вдох/скрип; босс — низкий гул |
| Урон по героине | ойк + тупой удар |
| Лут | редкий — колокольчик, уникальный — аккорд |
| Новый уровень | восходящий арпеджио |
| UI | мягкие щелчки дерева/бумаги |

## Правила

- Предупреждение врага всегда слышно, даже в каше (ducking SFX_Hero на −4 дБ на время замаха босса).
- Форматы: SFX — WAV → Vorbis, Decompress On Load; музыка — Vorbis, Streaming.
- Громкость: нормализация −16 LUFS для музыки, пики SFX ≤ −3 dBFS.
- Источники звуков: свои записи, CC0 (Kenney, Sonniss GDC bundle) или генерация — лицензию записывать в `Assets/_Project/Audio/LICENSES.md`.
