# Прокачка и билды

## Числа (Sim/Progression/HeroOps, Sim/Enemies/EnemyDb)

| Что | Формула |
|---|---|
| Опыт до следующего уровня | `30 + 25 × L^1.6` (ур.1 → 55, ур.5 → ~360, ур.10 → ~1025) |
| Максимальный уровень | 40 |
| Здоровье / мана героини | 60 + 12(L−1) / 40 + 6(L−1) |
| Регенерация | здоровье 1 + 0.1L, мана 4 + 0.25L в секунду |
| Крит | 5% × 150% базово |
| Здоровье врага | база × (1 + 0.22(L−1)) × (волшебный 2.2, редкий 4.5) |
| Урон врага | база × (1 + 0.12(L−1)) × (волшебный 1.1, редкий 1.25) |
| Опыт за врага | база × (1 + 0.15(L−1)) × (волшебный 2.5, редкий 5); ×0.5, если героиня выше на 5+ |

Уровень зоны = базовый + номер захода (не больше +3). Босс на 1 выше зоны.

## Ориентиры темпа

| Момент | Уровень героини |
|---|---|
| Конец пролога (Серый Глашатай) | 2–3 |
| Гнилые топи (зона 3) | 3–6 |
| Выцветший лес (зона 7) | 7–10 |
| Чернильные катакомбы (зона 11) | 11–14 |

Если плейтест показывает отставание больше чем на 2 уровня — сначала опыт за врага, потом кривая.

## Навыки

- Каждый уровень — 1 очко навыка. Ранг: +12% урона (`SkillDb.RankDamagePct`). Максимум 10 (у «Шедевра» 5).
- Навык открывается на своём уровне сразу с рангом 1 (`HeroOps.UnlockSkills`).

## Билды (что держим в голове при новых вещах)

- **Алый подрывник**: «Брызги» + «Золотой взрыв», область и урон алым.
- **Лазурный контролёр**: «Лазурная волна» + перезарядка, сопротивления.
- **Чернильный каллиграф**: «Чернильный разлив» + «Росчерк», здоровье за убийство.
Каждый новый уникальный предмет или пассив должен усиливать хотя бы один билд и не быть «обязательным» для всех.

## Дорожная карта

1. Дерево пассивов «Палитра» (≈60 узлов, 3 ветви по пигментам) — в `Sim/Progression/PassiveTree`, узлы дают `StatBlock`. Сохранение — список id узлов в `HeroState`.
2. Поддержки к навыкам (как камни поддержки в PoE): «Разбрызгивание» (+снаряды), «Густой слой» (+урон, −скорость).
3. Перераспределение за золото у Тётушки Гуашь.

Любая правка формул → тесты в `HeroAndQuestTests` + обновить таблицу выше.
