# Экономика и баланс

## Где числа

| Что | Файл |
|---|---|
| Здоровье/урон/опыт монстров, элита | `Sim/Enemies/EnemyDb.cs` |
| Навыки | `Sim/Skills/SkillDb.cs` |
| Героиня, опыт | `Sim/Progression/HeroOps.cs` |
| Лут, золото, зелья | `Sim/Items/Loot.cs`, `ItemGen.cs` |
| Цены | `Sim/Items/Vendor.cs` |
| Плотность и уровни зон | `Sim/World/ZoneDb.cs` |

## Целевые ощущения

| Метрика | Цель |
|---|---|
| Время убийства обычного врага навыком своего уровня | 1–2 удара «Мазка» / 1 взрыв |
| Редкий монстр | 4–8 с |
| Босс зоны | 45–90 с |
| Проход дикой зоны | 6–10 мин |
| Смерть от обычной стаи при ошибке | нет; от редкой — да, если стоять под ударами |
| Золото за зону | хватает на 1 волшебную вещь или 3–4 зелья |
| Редких предметов за зону | 2–4 (вместе с боссом) |

## Источники и траты золота

Источники: монстры (35%/100%), продажа (= Value), задания. Траты: покупка (3× Value), зелья (15 + 2×уровень). Дальше: перераспределение навыков, крафт, тайник. Если золото копится без дела — новые траты, а не урезание дохода.

## Как проверять

1. Быстро — тест-симуляция в `tools/SimTests` (по образцу `NormalMonsters_DropItemsSometimes`): прогнать 1000 убийств и посмотреть средние.
2. Для времени убийства: `DamageCalc.RollSkill` против `EnemyDb.LifeAt` для уровней 1–15 → таблица «ударов до смерти» (пишите как тест с выводом в `TestContext.WriteLine`).
3. Вживую — плейтест по чек-листу из `playtest-qa`, засечь время зоны и уровень на выходе.

## Правила правок

- Меняйте одну ручку за раз, записывайте «было → стало и почему» в описании коммита.
- Сначала множители зон/монстров, потом формулы.
- После правки: `dotnet test tools/SimTests`, обновить таблицы в `progression-builds`, `items-loot`, `enemies-bosses`.
