# Эффекты и сочность

## Что уже есть (Game/Fx/Fx.cs)

| Вызов | Что делает | Стоимость |
|---|---|---|
| `FxSystem.Splash(pos, color, count, speed, size)` | капли с гравитацией, отскакивают от пола; 25% капель — случайная краска | одна система частиц на игру |
| `FxSystem.Explosion(pos, color, radius, shake)` | вспышка-сфера, кольцо, брызги, 2–8 клякс, тряска | 2 временных объекта |
| `FxSystem.Ring(pos, color, radius)` | расходящееся кольцо по полу | 1 объект |
| `FxSystem.Decal(pos, color, size)` | клякса на полу на 12 с, кольцевой пул 160 | без аллокаций |
| `FxSystem.Text(pos, text, color, big)` | всплывающее число/надпись | рисует GameUI |
| `Telegraph.Circle/Line` | предупреждение врага, заполняется к удару | 2 квада |
| `CameraRig.Shake(amount)` | тряска (квадрат «травмы», затухает) | — |

## Правила сочности

- Размер эффекта ∝ силе: «Мазок» — 4–10 капель без тряски; «Золотой взрыв» — взрыв 3.5 м, тряска 0.3; «Шедевр» — 7 цветных взрывов + 0.8.
- Цвет = пигмент навыка. Raw-удары — случайная яркая краска.
- Смерть любого врага — взрыв краски: обычный 0.08 тряски, босс 0.9 + салют.
- Урон по героине — красные числа, небольшая тряска ∝ доле здоровья.
- Тряска суммируется, но ограничена 1.0. Слишком часто трясёт — уменьшить, а не убрать.

## Производительность

- Не создавать `ParticleSystem` на каждый эффект — только `FxSystem.Splash` (Emit в общую систему).
- Временные объекты (`AddPulse`) живут ≤ 0.6 с и уничтожают свой материал.
- На телефоне: лимит частиц 3000 → 1500, клякс 160 → 80 (константы в `FxSystem`).

## Дорожная карта шейдеров (URP, Shader Graph)

1. **Toon Lit**: 2–3 ступени освещения + цветной эмбиент; замена `Mats.Lit`.
2. **Контур** через Renderer Feature (обратные нормали или по глубине) — 1–2 px тёмно-фиолетовый.
3. **Покраска мира**: кляксы как декали URP (Decal Projector) вместо квадов — ложатся на стены.
4. **Растворение** врагов в краску при смерти (noise + emission по краю).
5. **Мазки на земле**: процедурная текстура холста на полу зон.
Каждый шаг — отдельный коммит со скриншотом до/после (см. `playtest-qa`).
