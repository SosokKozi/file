# Лагерь, NPC и задания

## Сюжет одной строкой

Серый Куратор выпил краски мира. Художница **Мирра** просыпается в Пепельной часовне, побеждает Серого Глашатая и выходит в лагерь «Радуга» — последнее место, где помнят цвета. Каждая побеждённая тварь лопается краской: героиня буквально возвращает миру цвет.

## Путь игрока

Пролог (часовня, мало врагов, босс) → портал → лагерь → Мольберт путей → Гнилые топи → Выцветший лес → Чернильные катакомбы → (дальше: Мастерская Куратора).

## Задания (Sim/Quests)

Статусы: `Locked → Available → Active → ReadyToTurnIn → Done`. Открытие — `RequiresQuest` / `RequiresZone`, пересчёт — `QuestOps.Refresh` (после убийства босса, входа в зону, сдачи).

| Id | Название | Цель | Награда |
|---|---|---|---|
| q_awakening | Пробуждение | убить босса пролога (авто) | 40 опыта, 20 золота |
| q_marsh | Цвет из тины | Тинная Матрона | 150 / 80 / редкий предмет |
| q_forest_hunt | Очистить холст | 40 врагов в Выцветшем лесу | 300 / 150 / редкий |
| q_ink | Пролитые чернила | Великий Ластик (после q_marsh) | 600 / 300 / уникальный |

Новое задание: `QuestDef` (три реплики: предложение, в процессе, сдача), при новом типе цели — `Objective` и ветка в `QuestOps.OnKill`/новом событии; тест по образцу `KillCountQuest_CompletesAndPaysOut`.

## Тон текста

- Коротко: реплика NPC — до 2 предложений, название задания — 2–3 слова.
- Мир мрачный, люди тёплые и с юмором («Почти ничего не краденое»).
- Краски и живопись в каждой метафоре: холст, мазок, растушёвка, грунт.
- На «ты» с героиней — только Гуашь; остальные на «вы».

## Лагерь

- В лагере нет врагов, здоровье полное, зелий минимум 3, товар обновляется, игра сохраняется.
- Подсказка «Пробел — имя» над ближайшим NPC; окно разговора блокирует удары.
