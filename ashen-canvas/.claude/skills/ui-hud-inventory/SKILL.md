# Интерфейс

## Сейчас: IMGUI (`Game/UI/GameUI.cs`, `GameUI.Windows.cs`)

Быстро для прототипа: всё кодом, без префабов. Виртуальный экран высотой 1080, ширина по пропорциям, `GUI.matrix` масштабирует.

| Элемент | Где |
|---|---|
| Сферы здоровья/маны | слева/справа внизу, заполнение снизу вверх |
| Хотбар | центр внизу: зелье (1) + 6 навыков; перезарядка — затемнение сверху вниз и секунды; нет маны — синий налёт |
| Опыт | тонкая полоса над низом экрана + «очки навыков» |
| Мини-карта | справа вверху: пол зоны, героиня, NPC/порталы, босс |
| Трекер заданий | справа под картой |
| Название зоны | крупно 6 с при входе, затем мелко сверху |
| Сообщения | центр сверху, 4.5 с: новый уровень, навык, задание, «Сумка полна» |
| Подписи лута | кнопки цвета редкости над предметами, не перекрываются |
| Окна | I — сумка, C — героиня, K — навыки; разговор, торговец, Мольберт, пауза (Esc), смерть |

Клики по окнам и подписям не превращаются в удары: каждый прямоугольник регистрируется через `Block(rect)`, `PointerOverUi` проверяет их.

## Управление (ПК)

WASD — бег, мышь — прицел, ЛКМ/ПКМ/Q/E/R/F — навыки, 1 — зелье, Пробел — говорить/подобрать, I/C/K — окна, Esc — назад/пауза. Подсказка внизу экрана в прологе до 2 уровня.

## Правила текста

Русский, коротко: кнопки 1–2 слова («Принять», «Сдать задание», «Уйти»), сообщения ≤ 6 слов. Числа — без лишних нулей. Красное — нельзя/опасно, жёлтое — награда, синее — мана/волшебное.

## Переход на UI Toolkit (до альфы)

1. `UIDocument` + UXML/USS на окно: `Hud.uxml`, `Inventory.uxml`, `Character.uxml`, `Skills.uxml`, `Dialog.uxml`, `Vendor.uxml`.
2. Контроллеры читают те же данные (`GameState`, `Hero.Stats`) — логика уже в Sim, переносится только отрисовка.
3. Подписи лута и числа урона — один `VisualElement`-слой с пулом меток, позиции из `WorldToScreenPoint`.
4. Перетаскивание предметов, сравнение с надетым в подсказке, сетка разных размеров предметов (как в Diablo/PoE) — после переноса.

## Геймпад и телефон (дальше)

- Геймпад: левый стик — бег, правый — прицел (или автонаведение на ближайшего), кнопки лиц + бамперы — 6 навыков. В Input System — Action Map `Gameplay`.
- Телефон: виртуальный стик слева, 4–6 круглых кнопок справа, автоприцел, подбор лута касанием подписи; размер кнопок ≥ 9 мм.
