# Бой и навыки

## Пигменты

| Element | Название | Цвет | Смысл |
|---|---|---|---|
| Raw | удар | кремовый / случайная краска | сама кисть, режется бронёй |
| Crimson | алый | #FF3B4A | «огонь»: взрывы, брызги |
| Azure | лазурь | #2FB8FF | «холод»: замедление |
| Golden | золото | #FFC928 | «молния»: мощные отсроченные взрывы |
| Ink | чернила | #8A3CFF | «яд/хаос»: урон по времени |

Цвет пигмента = цвет эффекта, кончика кисти и текста навыка. Мир серый — краска всегда читается.

## Формула (Sim/Combat/DamageCalc)

```
урон = (кисть[min..max] + WeaponFlat) × Effectiveness + FlatDamage
     × (1 + (DamagePct + ПигментPct + (ранг−1)×12) / 100)
     × (крит ? CritMulti/100 : 1)
Raw:     × (1 − min(75%, броня / (броня + 5×урон)))
пигмент: × (1 − clamp(сопротивление, −60, 75)/100)
```

Меняете формулу — меняйте тест `HeroAndQuestTests.Mitigation_IsCapped` / `SkillDamage_GrowsWithRank` и таблицу в `progression-builds`.

Новый навык:
1. `SkillDef` в `SkillDb.All` (числа) и, если нужен новый `SkillKind`, ветка в `SkillCaster.TryCast` (геометрия и эффекты).
2. Урон — только через `GameRoot.HitEnemy` / `SkillCaster.HitArea`: там защита, тексты урона, смерть, опыт, лут.
3. Эффект: цвет пигмента, брызги + клякса на полу, тряска пропорционально силе (см. `vfx-juice`).
4. Тест: открывается на своём уровне (`Leveling_UnlocksSkills_IntoHotbar` проверяет все).

## Хотбар и ввод

6 ячеек: ЛКМ, ПКМ, Q, E, R, F (`HeroState.hotbar`). Новый навык сам встаёт в первую пустую ячейку. Переназначение — окно навыков (K). Удержание клавиши повторяет навык по готовности.

## Ощущение удара

- Каждый удар: число урона (жёлтое и крупное для крита), «сплющивание» врага (`Enemy.punch`), брызги.
- Смерть врага — взрыв случайной яркой краски: мир получает цвет обратно. Это главный визуальный «крючок» игры, не убирайте.
- Не добавляйте хит-стоп длиннее 50 мс и тряску на каждый «Мазок» — устаёт глаз.

## Мана

База 40 + 6/уровень, восстановление 4 + 0.25×уровень в секунду. «Мазок» бесплатный — героиня никогда не остаётся без атаки.
