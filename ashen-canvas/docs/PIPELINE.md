# Пайплайн разработки «Пепельного холста»

## Этапы проекта

| Этап | Цель | Готово, когда |
|---|---|---|
| **0. Прототип** (сейчас) | весь цикл играбелен на болванках | пролог → лагерь → 3 зоны, лут, задания, сохранения; тесты зелёные |
| **1. Вертикальный срез** | один кусок игры в финальном качестве | героиня, 3 врага, Серый Глашатай и часовня — настоящие модели и анимации; звук; мультяшный шейдер; UI Toolkit |
| **2. Альфа** | весь контент первого акта | 5–6 зон, 8–10 боссов, дерево пассивов, крафт, тайник, геймпад |
| **3. Бета** | баланс и полировка | эндгейм «Холсты», настройки, локализация EN, производительность на телефоне |
| **4. Релиз** | сборки и магазин | ПК (Steam), затем мобильные |

## Поток одной фичи

```
идея ─► навык проекта (какие правила уже есть) ─► Sim: данные + логика + тест
     ─► Game: показ, ввод, эффекты ─► dotnet test + CompileCheck
     ─► Unity (MCP): консоль, тесты, Play-смоук ─► чек-лист playtest-qa ─► коммит
```

1. **Спроси навык.** Каждая область описана в `.claude/skills/<область>/SKILL.md`; мод `jev-skill-suggestion` подставляет нужный сам.
2. **Сначала Sim.** Числа и правила — в `Assets/_Project/Code/Sim`, без UnityEngine; сразу тест в `Tests/EditMode`.
3. **Потом Game.** MonoBehaviour только вызывает Sim, двигает объекты, рисует эффекты и UI.
4. **Проверка без Unity** (в облаке тоже): `dotnet test tools/SimTests`, `dotnet build tools/CompileCheck` и `-p:NewInput=true`.
5. **Проверка в Unity** (локально, через Unity MCP): консоль чистая, EditMode-тесты, Play 30 секунд.
6. **Обнови документацию:** таблицы в навыках, если поменялись числа или правила.
7. **Коммит** — одна фича, сообщение «что и зачем».

## Пайплайн 3D-ассетов

```
1. Каталог        asset_catalog.json: id, имя, рост, промпт       (дизайн)
2. Болванка       PlaceholderFactory: силуэт + цвета              (код, сразу в игре)
3. Генерация      tools/tripo → Art/Generated/<id>.glb            (Tripo API, позже)
   или сборка     Blender MCP / tools/blender                     (вручную или Claude)
4. Доводка        Blender: масштаб, ось, узлы Body/BrushPivot/BrushTip, ретопо, цвета
5. Импорт         Resources/Models/<id>.glb → glTFast              (Unity)
6. Проверка       скриншот с игровой камеры, бюджет, draw calls    (playtest-qa)
7. Каталог        source: final
```

Пока Tripo не подключён, шаги 3–4 пропускаются — игра полностью работает на болванках. Подключение Tripo: получить ключ → `TRIPO_API_KEY` в переменных окружения (не в репозитории) → сверить API с документацией → `python3 tools/tripo/tripo_generate.py --only hero --run`.

## Анимации

Прототип — процедурная анимация узлов. Вертикальный срез: риг Humanoid, клипы (Idle, Run, касты, Dash, Hit, Death), Animator с маской верхней половины (`characters-animation`). Источники: ручная анимация в Blender, Mixamo для черновиков, авто-риг Tripo (если тариф позволяет).

## Звук

Вертикальный срез: микшер, пул источников, 15 звуков первой очереди, музыка часовни и лагеря (`game-audio`).

## Инструменты Claude

| Инструмент | Где работает | Для чего |
|---|---|---|
| Навыки `.claude/skills` | везде | правила и числа по областям |
| `jev-skill-suggestion` | Claude Code 2.1.287+ | автоматический выбор навыка |
| `dotnet` (SimTests, CompileCheck) | везде, включая облачные сессии | проверка логики и компиляции |
| Unity MCP (`unityMCP`) | локально, Unity открыт, сервер на 8080 | консоль, тесты, Play, настройки, профайлер |
| Blender MCP (`blender`) | локально, аддон подключён (9876) | сборка и доводка моделей, экспорт glb |
| Tripo API | везде, нужен ключ | генерация моделей по промптам |

## Ветки и коммиты

- `main` — всегда собирается, тесты зелёные.
- Фичи — в ветках `feature/<кратко>`, слияние после проверки по чек-листу.
- Большие бинарники (`.fbx`, `.blend`, `.png`, `.wav`) — через Git LFS (`.gitattributes` уже настроен). `.glb` при необходимости добавить туда же.

## Риски и решения

| Риск | Решение |
|---|---|
| Сгенерированные модели «плывут» по стилю | общий `style` в каталоге, обязательная доводка в Blender, скриншот-проверка |
| IMGUI тормозит и выглядит прототипно | перенос на UI Toolkit до альфы (`ui-hud-inventory`) |
| Шейдеры из `Shader.Find` пропадают в сборке | *Always Included Shaders* или материалы-ассеты (`unity-mcp-workflow`) |
| Перегруз эффектами на телефоне | лимиты частиц/клякс в `FxSystem`, профайлинг на устройстве |
| Баланс «на глаз» | тест-симуляции в `tools/SimTests` (`economy-balance`) |
