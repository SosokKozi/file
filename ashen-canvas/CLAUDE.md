# Пепельный холст (Ashen Canvas)

Изометрическая ARPG в духе Path of Exile и Diablo, мультяшная, с яркими взрывами и брызгами краски. Героиня — художница Мирра — карает врагов кистью. Мир выпит до серого Серым Куратором; каждая побеждённая тварь лопается краской.

Путь игрока: мрачный пролог «Пепельная часовня» (мало врагов, босс Серый Глашатай) → лагерь-хаб «Радуга» (торговцы, задания) → процедурные зоны: Гнилые топи → Выцветший лес → Чернильные катакомбы.

Движок: **Unity 6 LTS, URP, C#**. Сейчас — играбельный прототип: весь мир, персонажи и интерфейс строятся кодом, модели — болванки из примитивов.

## Где что лежит

- `Assets/_Project/Code/Sim` — правила игры без UnityEngine: генерация зон, лут, урон, навыки, задания, прокачка. Тестируется в .NET.
- `Assets/_Project/Code/Game` — слой Unity: `Boot/GameRoot` (корень, зоны, бой), `Player/Hero`, `Enemies/Enemy`, `Combat/SkillCaster`, `World/ZoneView`, `Fx`, `UI/GameUI` (IMGUI), `Art/AssetProvider` + `PlaceholderFactory`.
- `Assets/_Project/Code/Editor` — меню «Ashen Canvas» (сцена Boot, сохранения, отчёт по ассетам).
- `Assets/_Project/Art/asset_catalog.json` — каталог моделей с промптами; `Resources/Models/<id>.glb` заменяет болванку.
- `tools/SimTests`, `tools/CompileCheck` — проверки без Unity. `tools/tripo` — генерация моделей (Tripo API), `tools/blender` — скрипты Blender.
- `docs/PIPELINE.md` — пайплайн разработки, `docs/GDD.md` — дизайн игры.
- `.mcp.json` — MCP-серверы Blender и Unity (работают, когда Claude Code запущен на том же компьютере, что и программы).

## Главные правила

1. **Правила игры — в Sim**, Unity-слой только показывает. В Sim нет `UnityEngine`.
2. **Всё случайное в правилах — от seed** (`Sim.Core.Rng`). `UnityEngine.Random` — только косметика эффектов.
3. **Каждый удар врага предупреждает заранее** кругом или полосой на полу; от удара можно уйти.
4. **Генератор не выпускает зону без проверки проходимости** (`DungeonGen.Validate`).
5. **Игра никогда не ждёт ассетов**: у каждого id из каталога есть болванка в коде.
6. Перед коммитом: `dotnet test tools/SimTests` и `dotnet build tools/CompileCheck` (+ `-p:NewInput=true`). Не использовать API, которых нет в UnityEngine 2021.3, без обновления CompileCheck.
7. Сцены и префабы не правим как текст — всё строится кодом.
8. Интерфейс и тексты — на русском, коротко. Цель — 60 FPS.
