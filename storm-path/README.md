# Тропа бурь (рабочее название)

Roguelite-раннер для телефонов и ПК на Unity 6 (URP) в стилизованной рисованной графике. Пока здесь только навыки Claude Code и описание игры (`CLAUDE.md`); сам Unity-проект создаётся следующим шагом.

Чтобы работать над игрой с Claude Code, запускайте `claude` **в этой папке** (`storm-path/`): тогда подключатся её навыки и Claude Code предложит установить официальный плагин Unity.

Позже эту папку можно вынести в отдельный репозиторий целиком.
