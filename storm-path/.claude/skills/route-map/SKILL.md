# Карта маршрута

## Устройство

Карта — направленный граф без циклов, разбитый на **ряды** 0…N. Игрок всегда идёт на следующий ряд по одному из рёбер текущей точки.

- Ряд 0: старт. Ряды 1–3: обучение (по одной точке, без выбора; в повторных забегах — одна разминка).
- Ряд 4: святилище выбора ветки (одна точка).
- Ряды 5…N−2: акт с развилками (3–4 точки в ряду).
- Ряд N−1: привал (все пути сходятся сюда или в 2 привала).
- Ряд N: финал акта (одна точка).

## Алгоритм (seed → карта)

```
rng = Rng(seed ^ ACT_SALT[act])
1. Колонки: ширина карты W = 4. Проводим P = 4–6 «троп» от ряда 5 до N−2:
   каждая тропа на ряду r стоит в колонке c, на следующем ряду идёт в c−1, c или c+1 (в пределах 0..W−1).
2. Запрет пересечений: тропа не может перейти c → c+1, если другая тропа на том же шаге идёт c+1 → c.
3. Точки = уникальные (ряд, колонка), рёбра = уникальные переходы троп.
4. Каждая точка ряда 5 соединена со святилищем, каждая точка ряда N−2 — с привалом.
5. Назначить типы (ниже), затем биомы и сложность.
6. Проверить ограничения; при нарушении — новая попытка с rng.next() (до 50), потом ручной шаблон карты.
```

Развилки появляются там, где из точки выходит 2–3 ребра. Цель: 40–60 % точек акта имеют ≥ 2 выхода; у игрока минимум 3 настоящих выбора между святилищем и привалом.

## Типы точек

| Тип | Доля в акте | Ограничения |
|---|---|---|
| Уровень биома | 50–60 % | не больше 3 подряд одного биома на любом пути |
| Элитный уровень | 10–15 % | не раньше ряда 7; не два подряд |
| Святилище | 10 % | минимум одно на любом пути до ряда N−3 |
| Лавка | 5–10 % | минимум одна достижимая; не в последних 2 рядах акта |
| Загадка | 10 % | — |

Правило выбора: у соседних развилок (выходы одной точки) **разные** типы или разные биомы, иначе выбор пустой.

## Биомы и сложность

- Биом назначается «кусками»: соседние точки чаще одного биома (вероятность 0.6), чтобы путь ощущался как путешествие через земли, а не мешанина.
- Каждый акт: 3 биома из списка (см. `biomes-mechanics`); финал — биом акта.
- Сложность точки `k = базовая_акта + 0.04 × (ряд − 5)`, элита +0.2, ограничение 0..1. Акт I базовая 0.15, акт II — 0.45.
- Показываем игроку сложность на карте (1–3 черепа), биом (иконка + цвет) и тип точки.

## Проверки карты (обязательные)

1. Из старта достижим финал; из каждой точки есть путь к финалу (нет тупиков).
2. На **любом** пути есть хотя бы одно святилище и одна возможность лечения (привал или лавка) до финала.
3. На любом пути встречаются минимум 2 разных биома.
4. Нет пересекающихся рёбер (проверка отрезков на плоскости).
5. Каждая точка уровня получает seed уровня `hash(seed, ряд, колонка)` и проходит `traversal-validation` до показа карты (или лениво при наведении — но до входа).

## Отображение

- Карта прокручивается вертикально снизу вверх; пройденный путь подсвечен, доступные точки пульсируют.
- При наведении/касании — карточка: биом, механика («За тобой идёт огненный шторм»), сложность, награда.
- Стиль: пергамент/рисованная карта мира с туманом войны над непройденными рядами (см. `art-direction-stylized`).
