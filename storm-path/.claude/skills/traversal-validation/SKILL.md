# Проверка проходимости

Генератор не отдаёт игроку уровень, который не прошёл **уровень 1**. Уровни 2 и 3 гоняются офлайн на тысячах seed при каждом изменении генератора, физики или блоков.

## Уровень 1 — аналитическая проверка (в игре, < 5 мс на уровень)

1. Из `LevelData` строим граф: узлы — опорные поверхности (верх платформы), рёбра — переходы.
2. Ребро A → B существует, если B достижима **базовыми движениями** при скорости из диапазона `[0.85 V, ожидаемая]`:
   - зазор по Z ≤ дальность прыжка (полный или с двойным, по таблице) − 1.5 м запаса;
   - подъём ≤ высота прыжка − 0.3 м;
   - для перехода шагом — подъём ≤ 0.45 м;
   - нет твёрдого препятствия на траектории (дискретизация параболы по 0.25 м против AABB);
   - сдвиг по X достижим: `|Δx| ≤ LAT × время_полёта − ширина_цели/2`.
3. Должен существовать путь от старта до финиша **без рёбер способностей**.
4. Отдельно добавляем рёбра способностей (таран через хрупкое, уклонение сквозь лазер, туманный шаг через разрыв) и проверяем, что короткий путь каждой ветки реально короче базового.
5. Механики биомов (по расчёту времени пути на `0.85 V`):
   - Пекло: отрыв от шторма в каждой точке пути ≥ 8 м;
   - Хронопустошь: запас таймера ≥ 15 % до каждого следующего обязательного кристалла;
   - Грозовые пики: во всех зонах ударов есть полоса шириной ≥ 3 м, нет ударов в запретных зонах.

## Уровень 2 — бот (офлайн, детерминированная симуляция)

Тот же `Sim` (чистый C#), что и в игре, без рендера. Боты:

| Бот | Поведение | Требование |
|---|---|---|
| Новичок | реакция 0.25 с, без идеальных приземлений, иногда задевает стены (шум ±0.4 м по X) | финиширует в ≥ 95 % seed; урон ≤ 60 % HP |
| Опытный | идеальные приземления, оптимальные прыжки | задаёт эталонное время уровня |
| Мощь / Ловкость / Мистика | опытный + способность на коротких путях | выигрыш времени ветки в пределах ±5 % между ветками |

Бот планирует по графу из уровня 1 (A* по времени), а исполняет через обычный ввод (`InputFrame` по тикам) — так он проверяет реальную физику, а не только граф.

## Уровень 3 — карта маршрута

- Все проверки из `route-map`: связность, нет тупиков, святилище и лечение на каждом пути, разнообразие биомов, нет пересечений рёбер.
- Симуляция забега ботом-новичком по случайному пути: доживает до финала акта в ≥ 70 % забегов (иначе урон или лечение не сбалансированы).

## Массовые прогоны

```sh
# EditMode-тесты генератора и бота (без окна, работает в CI и в облачной сессии Claude при установленном Unity)
Unity -batchmode -nographics -projectPath . -runTests -testPlatform EditMode \
      -testFilter "Validation" -testResults Logs/validation.xml -logFile Logs/unity.log
```

- `LevelSeedSweepTests`: 2 000 seed на каждый биом × 5 значений k.
- Отчёт: доля проходимых, распределение времени, топ-20 провальных seed с причиной (номер блока, тип ребра, механика).
- Провальные seed автоматически становятся регрессионными тестами (`Tests/Seeds/failed.json`).
- В CI: GitHub Actions с образом `game-ci/unity-test-runner` (нужна лицензия Unity в секретах репозитория).

## Порог выпуска

| Метрика | Порог |
|---|---|
| Уровень 1 пройден | 100 % выданных уровней (иначе генератор перегенерирует) |
| Бот-новичок финиширует | ≥ 95 % seed на биом и k |
| Разброс веток по времени | ≤ ±5 % |
| Время генерации + проверки уровня | ≤ 50 мс на телефоне |
