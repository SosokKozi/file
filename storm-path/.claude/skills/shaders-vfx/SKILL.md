# Шейдеры и эффекты

## Основной шейдер персонажей и окружения (`Stylized/Lit`)

Shader Graph (URP), Lit-подобный, но со своим освещением:

```
albedo   = tex(BaseMap) * BaseColor                 // рисованная текстура уже содержит тени
NdotL    = dot(N, L_main) * 0.5 + 0.5               // half-Lambert
ramp     = tex(RampTex, float2(NdotL * shadowAtten, 0.5))   // 2–3 ступени, мягкий край 0.05
light    = lerp(ShadowTint, MainLightColor, ramp)
rim      = pow(1 - saturate(dot(N, V)), RimPower) * RimStrength * ramp
spec     = step(1 - SpecSize, dot(N, H)) * SpecStrength      // стилизованный блик, только металл/кристаллы
color    = albedo * (light + ambientSH * AmbientStrength) + rim * RimColor + spec
```

- Главный свет берётся через Custom Function `GetMainLight(shadowCoord)`; дополнительные источники — упрощённо (без рампы) или не учитываются на телефоне.
- `ShadowTint` задаётся в биоме (холодный фиолетово-синий), а не чёрный.
- Параметры — в `BiomeLightingProfile` (ScriptableObject), чтобы переключать атмосферу без правки материалов.

## Контур

- Персонажи и важные объекты: «перевёрнутая оболочка» (второй проход, вершины по нормали на 1.5–3 мм, cull front, цвет — тёмный оттенок альбедо, а не чёрный). Нормали для контура запекаются в цвет вершин, чтобы не рваться на острых углах.
- Окружение: без контура или по глубине/нормалям через Renderer Feature только на ПК.

## Эффекты (что и как)

| Эффект | Как сделать | Телефон |
|---|---|---|
| Огненная стена шторма | лента мешей с прокруткой шума + gradient map (жёлтый → оранжевый → бордовый) + эмбеды-частицы + искажение экрана | без искажения, меньше частиц |
| Жар у края шторма | экранный градиент по краям + дрожание камеры | — |
| Зона удара молнии | декаль-круг (URP Decal Projector) с заполнением по времени `fill = t / warn` и зигзаг-узором | проекция на плоскость вместо декали |
| Удар молнии | меш-молния (ломаная, 3 кадра смены формы) + вспышка + Point Light 0.1 с + частицы | без Point Light |
| Кристалл времени | вращение + френель + пульс; подбор — вспышка и «+3 с» в мире | — |
| Таран (Мощь) | вытянутый шлейф-конус, ударная волна на разбивании, обломки (пул из 20) | обломков 8 |
| Уклонение (Ловкость) | 2–3 полупрозрачные копии силуэта (afterimage) + шлейф ветра | 1 копия |
| Туманный шаг (Мистика) | растворение по шуму на старте, лента тумана, сборка из частиц на выходе; маркер точки выхода | — |
| Идеальное приземление | кольцо по земле + искры цвета биома | — |
| Небо | градиент + рисованные облака на картах (прокрутка) + солнце/луна | — |

Правила: эффекты в стиле «рисованной анимации» — чёткие формы, ступенчатое затухание, текстуры-флипбуки 4×4 или 8×8, gradient map вместо раскрашенных текстур (один флипбук — много цветов). Цвет эффекта = значение из языка цветов (`art-direction-stylized`).

Частицы: на ПК можно VFX Graph; на телефоне — только Particle System (Shuriken) или GPU-инстансинг мешей. Делайте один эффект с уровнями детализации, а не два разных.

## Постобработка (URP Volume)

| Эффект | ПК | Телефон |
|---|---|---|
| Bloom | да, порог 1.0 | лёгкий, половинное разрешение |
| Цветокоррекция (LUT на биом) | да | да |
| Виньетка | от скорости и низкого HP | да |
| Глубина резкости | только меню и карта | нет |
| Motion blur | по настройке | нет |
| SSAO | нет (тени нарисованы в текстурах) | нет |

## Уровни качества

| | Низкое (телефон) | Среднее | Высокое (ПК) |
|---|---|---|---|
| Масштаб рендера | 0.75 | 1.0 | 1.0 |
| Тени | одна каскадная, 1024, 30 м | 2048, 50 м | 2 каскада, 2048, 80 м |
| Частицы | ×0.4 | ×0.7 | ×1 |
| Контур окружения | нет | нет | да |
| MSAA | нет (FXAA) | 2× | 4× |

Бюджет кадра на телефоне: ≤ 120 SetPass, ≤ 250 тыс. треугольников, без прозрачных полноэкранных слоёв больше двух. Проверка — Frame Debugger и Unity Profiler на реальном устройстве (в связке с официальным плагином Unity и его навыком `urp-postprocessing`).
