# Основной цикл

## Забег

```
Старт → Обучение 1 → Обучение 2 → Обучение 3 → [Акт I: развилки] → Привал → [Акт II] → Финал
```

| Часть | Что происходит | Длительность |
|---|---|---|
| Обучение (3 уровня, без выбора) | бег и прыжок → кувырок и идеальное приземление → первая угроза и здоровье. Только в первом забеге; потом — один короткий разминочный уровень | 60–90 с каждый |
| Святилище выбора ветки | игрок выбирает Мощь, Ловкость или Мистику на этот забег (см. `abilities-progression`) | — |
| Акт (8–10 рядов карты) | на каждом шаге 2–3 точки на выбор (см. `route-map`) | 12–15 мин |
| Финал акта | особый уровень: самая сложная версия биома акта | 2–3 мин |

Забег целиком: 25–35 мин на ПК; на телефоне можно выйти между точками и продолжить позже (сохранение после каждой точки).

## Типы точек на карте

| Точка | Что даёт |
|---|---|
| Уровень биома | основной контент; награда — осколки (валюта забега) и случайный дар |
| Элитный уровень | тот же биом сложнее (k + 0.2), награда — редкий дар |
| Святилище | улучшение способности ветки (выбор 1 из 3) |
| Привал | лечение 40 % здоровья **или** улучшение дара |
| Лавка | купить дар или лечение за осколки |
| Загадка | короткий случайный уровень-испытание с риском и наградой |

## Валюты

- **Осколки** — внутри забега: лавка, повторный выбор дара. Сгорают в конце забега.
- **Эссенция** — между забегами: 10–30 % собранных осколков + бонус за пройденные акты. Тратится на дерево талантов и облики.
- Никаких покупок за реальные деньги, которые дают силу. Монетизация, если будет, — только облики.

## Дары (внутри забега)

Пассивные бонусы на один забег: «+10 % к скорости после идеального приземления», «молния лечит 5 HP, если увернулся», «таран заряжается от искр». У каждой ветки свой набор плюс общий. Выбор всегда 1 из 3, повторный выбор — за осколки.

## Мета-прогрессия

Дерево талантов (см. `abilities-progression`) открывает новые дары, вторую способность ветки, стартовые бонусы. Рост силы ограничен: опытный игрок без талантов должен проходить первый акт. Большая часть меты — **разнообразие** (новые дары, биомы, облики), а не сила.

## Режимы и соревнование

| Режим | Как |
|---|---|
| Обычный забег | случайный seed |
| Ежедневный | один seed на всех на сутки (UTC), одна зачётная попытка, отдельный рейтинг |
| Недельное испытание | seed + модификаторы («здоровья вдвое меньше», «шторм быстрее») |
| Уровень на время | любой пройденный уровень по его seed: таблица лидеров уровня |

Очки забега:

```
очки = Σ(уровни: 1000 × множитель_сложности × (эталон / время))
     + 50 × идеальные приземления
     + 200 × уровни без урона
     − 300 × смерти
```

Рейтинг принимается только по проверенной записи ввода (как в `competitive-modes` прототипа): сервер прогоняет симуляцию по seed и вводу.

## Смерть

Здоровье 0 — конец забега (с экраном итогов: путь по карте, лучшие моменты, полученная эссенция). Одно «второе дыхание» за забег можно получить даром или талантом.
