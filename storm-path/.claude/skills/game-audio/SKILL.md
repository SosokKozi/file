# Звук

## Микшер (Unity Audio Mixer)

```
Master
├ Music        (снимки: Map, Run, Danger, Pause)
├ SFX
│ ├ Hero       (шаги, прыжки, способности)
│ ├ Hazards    (шторм, молнии, обломки)
│ └ Pickups
├ Ambience     (ветер, огонь вдали, гром)
└ UI
```

- Громкости групп — экспортированные параметры, связаны с настройками (Общая, Музыка, Эффекты, Интерфейс).
- Приглушение: Duck Volume на Music по сигналу из SFX/Hazards (удар молнии, идеальное приземление); снимок `Danger` при HP < 30 %.
- Лимит голосов: шаги 2, искры/осколки 3, частые эффекты через пул `AudioSource`.

## Звуки по событиям

| Событие | Характер |
|---|---|
| Бег | шаги по материалу поверхности (камень, лёд, пепел, металл), темп от скорости |
| Прыжок / двойной / сальто | короткий «вжух» + шорох ткани; сальто — свист |
| Приземление мягкое / жёсткое / идеальное | глухо / тяжело с хрустом / яркий аккорд, высота растёт в серии |
| Таран | нарастающий гул 0.3 с + удар и каменный обвал при разбивании |
| Уклонение | резкий воздушный рез, стереосдвиг в сторону уклонения |
| Туманный шаг | всасывание (реверс) → тишина 0.05 с → мягкий выдох на выходе |
| Урон | удар + короткий вскрик героя (3–4 вариации), щит — стеклянный звон |
| Предупреждение молнии | треск нарастает к удару; по нему можно играть с закрытыми глазами |
| Огненный шторм | постоянный рёв, громкость и низкие частоты от расстояния (позиционно) |
| Кристалл времени | колокольчик + «тик» |
| Таймер < 5 с | учащённый тик |
| Карта маршрута | шуршание пергамента, звук выбора точки, у каждого биома свой короткий мотив при наведении |

Важное событие всегда дублируется визуально (см. `health-damage`).

## Адаптивная музыка

Трек на биом, 3–4 стема одного темпа, запускаются синхронно через `AudioSource.PlayScheduled(dspTime)`:

| Биом | Чем управляется интенсивность |
|---|---|
| Пустоши | скоростью героя |
| Пекло | расстоянием до шторма (ближе 20 м — ударные и хор, ближе 8 м — всё на пике) |
| Хронопустошь | остатком таймера (меньше 10 с — темп слоя «тиков» вдвое) |
| Грозовые пики | частотой ударов вокруг героя |
| Финал акта | отдельная композиция с нарастанием к концу |

Смена слоёв — плавно за 1–2 с, переход между треками — на сильную долю (такт).

Если адаптивность понадобится сложнее (переходы по тактам, вариации, параметры в реальном времени) — переходите на **FMOD Studio** или **Wwise**: обе бесплатны для небольших проектов (проверьте текущие условия лицензий).

## Импорт для телефона

| Тип | Load Type | Формат |
|---|---|---|
| Короткие эффекты (< 1 с) | Decompress On Load | ADPCM |
| Средние (1–5 с) | Compressed In Memory | Vorbis 70 % |
| Музыка, эмбиент | Streaming | Vorbis 50–60 % |

Моно для всех 3D-звуков; `Force To Mono` для эффектов. Громкость микса ≈ −16 LUFS; лимитер на Master. Официальный плагин Unity содержит навыки `audio-setup-mixers` и `optimize-audio` — используйте их для деталей настройки.

## Лицензии

Звуки из библиотек — только с лицензией, разрешающей коммерческое использование; файл `Assets/Audio/LICENSES.md` со списком источников. Никаких звуков и музыки из игр Riot и других игр.
