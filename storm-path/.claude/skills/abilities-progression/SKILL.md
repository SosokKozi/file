# Способности и прокачка

## Ветки

Игрок выбирает ветку в святилище после обучения; на один забег — одна ветка. Кнопка способности одна (ПК: `E` / ПКМ, телефон: отдельная кнопка, геймпад: RB).

| | Мощь | Ловкость | Мистика |
|---|---|---|---|
| Способность | **Таран**: рывок вперёд 10 м за 0.3 с | **Уклонение**: сдвиг в сторону 3.5 м за 0.2 с | **Туманный шаг**: перенос вперёд на 8 м |
| Особое | разбивает хрупкие объекты (трещины, руна Мощи); урон по герою −50 % во время рывка | неуязвимость 0.35 с; проходит сквозь удары и лазеры | игнорирует препятствия и пропасти между точками; точка выхода видна заранее |
| Перезарядка | 4 с | 2.5 с (2 заряда после улучшения) | 6 с |
| Ограничение | не в воздухе (на 1-м уровне ветки) | можно в воздухе | нельзя, если точка выхода не над твёрдой поверхностью: призрак-маркер краснеет |
| Облик | тяжёлая броня, искры от шагов | лёгкая кожа, шлейф ветра | мантия, туманный след |

Таран о неразрушаемую стену = обычный удар (потеря скорости), чтобы способность не была «кнопкой без риска».

## Улучшения в забеге (святилища, 1 из 3)

Пример набора Мощи: «Таран разгоняет на +8 м/с», «Разбитый объект даёт 5 осколков», «Таран доступен в воздухе», «Перезарядка −1 с», «После тарана 1 с без урона от шторма».
Ловкость: «Второй заряд», «Уклонение заряжает идеальное приземление», «Увернулся от молнии — +10 % скорости на 2 с».
Мистика: «Дальность +3 м», «Шаг сквозь огненный шторм отталкивает его на 10 м», «Выход из шага — мгновенно идеальное приземление».

Каждой ветке 12–15 улучшений; в одном забеге игрок видит 4–6 святилищ.

## Дерево талантов (между забегами, за эссенцию)

- Три ствола по веткам + общий (здоровье, щит, стартовые осколки, второе дыхание).
- Ствол ветки: открывает новые улучшения в пул святилищ, второй облик, вторую способность ветки (поздно в мете), например Мощь — «Сотрясение» (оглушает молнии на 2 с вокруг).
- Узлов ~40, полное дерево — 30–40 забегов. Сила от талантов ≤ 25 % от базовой; остальное — разнообразие.

## Как уровни учитывают способности

Генератор (`procgen-levels`) соблюдает:
1. **Проходимость без способности.** Каждая ветка — только короткий путь или бонус.
2. **Равная ценность.** На уровне есть короткие пути **для всех трёх веток**: хрупкая стена со скрытым ходом (Мощь), лазерный забор поперёк короткого пути (Ловкость), разрыв к верхнему маршруту (Мистика). Каждый экономит 1–2 с или даёт кристаллы/сферы. Ни одна ветка не получает больше 40 % суммарной выгоды уровня.
3. **Видимость.** Короткий путь ветки виден за ≥ 2 с и помечен руной цвета ветки (только для выбранной ветки руна светится).
4. Способность не должна ломать механику биома: туманный шаг сквозь огненный шторм отодвигает его, но не «телепортирует вперёд на 50 м»; уклонение не делает игрока неуязвимым к таймеру.

## Баланс

Метрика: среднее время уровня и средний урон по веткам на тысячах прогонов бота (`traversal-validation`) и по данным игроков. Ветки в пределах ±5 % по времени и ±15 % по урону на каждом биоме. Если ветка сильнее в одном биоме — это нормально (Ловкость в Грозовых пиках), но в среднем по акту — равенство.

## Данные

```csharp
[CreateAssetMenu] public class AbilityDef : ScriptableObject { public Branch branch; public float distance, duration, cooldown; public int charges; public bool airborne; }
[CreateAssetMenu] public class UpgradeDef : ScriptableObject { public Branch branch; public string title, text; public StatMod[] mods; public UpgradeDef[] requires; }
[CreateAssetMenu] public class TalentNode : ScriptableObject { public string id; public int cost; public TalentNode[] parents; public UpgradeDef[] unlocks; public StatMod[] mods; }
```

Тексты улучшений пишутся конкретно: «Перезарядка тарана −1 с», а не «Таран становится лучше».
