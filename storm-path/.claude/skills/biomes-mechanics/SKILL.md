# Биомы и механики

Опорные скорости (из прототипа): крейсерская `V = 21 м/с`, максимум `48`. «Скорость новичка» — `0.85 V` (без идеальных приземлений, с редкими ударами). Все формулы ниже считаются от неё, чтобы механика была честной для обычного игрока.

## Пустоши (базовый)

Без особой механики; учит чистому бегу. Используется для обучения и «передышки» между тяжёлыми биомами.

## Пекло — огненный шторм позади

Стена огня идёт за игроком по трассе.

| Параметр | Формула / значение |
|---|---|
| Стартовое отставание | 45 м − 15 м × k |
| Скорость шторма | `v(t) = min(0.80 V + 0.12 V × k + 0.004 V × t, 0.95 × 0.85 V)` |
| Контакт | 15 HP/с + замедление героя на 20 %; на краю за 6 м — жар (экран краснеет, звук), без урона |
| После смерти/падения | возрождение на контрольной точке, шторм отводится на 25 м назад |
| После удара о стену | шторм не ускоряется «вдогонку»: никакой резиновой подтяжки вперёд |

Правило честности: шторм **никогда** не быстрее `0.95 × скорость_новичка`. Значит, игрок без ошибок всегда отрывается, а пара ударов о стену сокращает отрыв, но не убивает сразу. Проверка — в `traversal-validation`: бот «новичка» финиширует с отрывом ≥ 8 м.

Уровень строится длиннее и прямее (меньше вертикали), с горящими обломками, которые падают **перед** игроком с предупреждением.

## Хронопустошь — гонка со временем

Над героем таймер. На трассе кристаллы времени.

| Параметр | Значение |
|---|---|
| Стартовый таймер | 20 с |
| Кристалл на основном пути | +3 с (k ≤ 0.5) … +2 с (k = 1) |
| Кристалл на рискованном ответвлении | +5 с |
| Таймер = 0 | 10 HP/с, пока не подберёшь кристалл; на финише — штраф к награде |
| Бонус | остаток таймера на финише × 20 очков |

Правило честности: генератор считает время прохождения **основного пути** на скорости новичка и проверяет, что в любой точке трассы
`таймер_в_точке ≥ 0.15 × (время до следующего кристалла)` — запас не меньше 15 %. Кристаллы основного пути не ставятся за препятствиями, требующими способности.

## Грозовые пики — удары молний

Над трассой грозовые облака; молнии бьют по земле.

| Параметр | Значение |
|---|---|
| Предупреждение | круг на земле + искры, 1.2 с (k = 0) … 0.8 с (k = 1); звук нарастания |
| Радиус | 2.5 м |
| Урон | 25 HP, неуязвимость 1 с после удара |
| Темп | 1 удар в 2.5 с (k = 0) … 1 в 0.9 с (k = 1) |
| Прицел | точка, куда игрок прибежит через время предупреждения, со случайным сдвигом ±3 м |
| Одновременно рядом с игроком | не больше 2 |

Правила честности:
1. В любой момент существует свободная полоса шириной ≥ 3 м через зону ударов.
2. Удары не ставятся на узкие балки и в точки приземления после обязательного прыжка (генератор помечает такие зоны как запретные).
3. Ветка Ловкость может увернуться **сквозь** удар (неуязвимость уклонения), Мощь — получает 50 % урона во время тарана, Мистика — переносится туманным шагом. Но базовый игрок обходит удары сменой полосы.

Награда за риск: удар молнии по проводнику-кристаллу рядом с игроком даёт ускорение («оседлать молнию»).

## Как добавить биом

1. Одна главная механика + 1–2 своих препятствия. Механика должна менять **решения** игрока, а не только визуал.
2. Опишите: параметры от k, правила честности (что гарантирует генератор), как проверяет бот, как взаимодействует с каждой веткой способностей.
3. Палитра и силуэты — в `art-direction-stylized`; язык опасностей общий для всех биомов.
4. Добавьте `BiomeDef` (ScriptableObject): id, название, палитра, набор блоков, параметры механики, музыка.

Идеи для следующих: **Затопленный храм** (вода поднимается, подталкивая вверх по трассе), **Теневой лес** (видимость ограничена, путь подсвечивают светлячки), **Ледник** (скользкие участки: меньше управление по сторонам, больше скорость).
