# Здоровье и урон

## Базовые числа

| Параметр | Значение |
|---|---|
| Здоровье героя | 100 (таланты: до 130) |
| Неуязвимость после урона | 1.0 с (герой мигает; угрозы проходят насквозь) |
| Отбрасывание | лёгкое, 1.5 м назад-вверх, без потери управления дольше 0.25 с |
| Потеря скорости при уроне | −20 % (не ниже 0.6 V) |

## Источники урона

| Источник | Урон | Примечание |
|---|---|---|
| Шипы, лезвия | 20 | предупреждение — сам вид объекта |
| Удар молнии | 25 | круг-предупреждение 0.8–1.2 с |
| Огненный шторм | 15/с | жар-предупреждение за 6 м |
| Таймер Хронопустоши = 0 | 10/с | пока не подобран кристалл |
| Горящий обломок | 15 | тень + свист за 1 с до падения |
| Падение в пропасть | 30 | возрождение на контрольной точке |
| Удар о стену | 0 | только потеря скорости и спотыкание (как в прототипе) |

Урон на сложности: `урон × (0.8 + 0.4 k)`. Ни один одиночный источник не наносит больше 35 % максимального здоровья.

## Предупреждения (обязательно)

1. Каждая атака, которую нельзя «увидеть заранее» как объект, имеет предупреждение ≥ 0.8 с: зона на земле, звук, свечение.
2. Зона предупреждения = зона урона (в пользу игрока допускается −10 %, никогда +).
3. Формы: круг — удар сверху, полоса — проносящийся объект, конус — выброс. Цвет опасности общий (см. `art-direction-stylized`), плюс форма для дальтоников.

## Лечение и защита

| Источник | Эффект |
|---|---|
| Привал на карте | +40 % здоровья |
| Лавка | +25 % за осколки |
| Сфера лечения на уровне | +10, редкие, на рискованных ответвлениях |
| Уровень без урона | +5 после финиша |
| Дары / таланты | щит 20 (поглощает первый удар каждого уровня), вампиризм от тарана и т. п. |

Щит отображается отдельным слоем полосы здоровья и тратится первым.

## Смерть

- HP = 0 → замедление времени 0.5 с, анимация падения, экран итогов забега.
- «Второе дыхание» (талант/дар, 1 раз за забег): вместо смерти — 30 % HP и 2 с неуязвимости.
- Смерть всегда объяснима: на экране итогов написано, что убило («Удар молнии, Грозовые пики, ряд 7»).

## Отображение

- Полоса здоровья в левом верхнем углу; при уроне — отрезок «утекает» с задержкой 0.4 с (видно, сколько потеряно).
- Ниже 30 % — пульсирующая красная виньетка и учащённое сердцебиение в звуке (выключается настройкой «Уменьшить эффекты»).
- Цифры урона над героем — только в режиме обучения и по настройке.

## Код

```csharp
public struct Health { public int max, hp, shield; public float invulnUntil; }
public enum DamageSource { Spikes, Lightning, FireStorm, Timer, Debris, Fall }
public readonly struct DamageEvent { public readonly DamageSource src; public readonly int amount; public readonly Vector3 from; }
// Sim: Health.Apply(DamageEvent, simTime) → возвращает фактический урон; события уходят в View (вспышка, звук, тряска).
```

Урон считается в симуляции по тикам (`simTime`), а не по `Time.time` — для повторов и рейтинга.
