# Тропа бурь (рабочее название)

Roguelite-раннер для телефонов и ПК в стилизованной «рисованной» графике (вдохновение — визуальный стиль игр по League of Legends, без заимствования персонажей, названий и ассетов Riot). Герой бежит по маршруту из точек: сначала обучение, потом развилки на 2–3 пути с разными биомами и механиками. Есть здоровье, способности трёх веток прокачки и процедурные уровни с гарантией прохождения.

Движок: **Unity 6 LTS, URP, C#**. Прототип механики бега (физика прыжков, кувырок, идеальное приземление) — `../index.html` из «Осколков скорости»; числа оттуда — стартовая точка.

## Навыки проекта (`.claude/skills/`)

| Навык | Когда нужен |
|---|---|
| `core-loop` | структура забега, награды, что сохраняется между забегами, режимы и рейтинг |
| `route-map` | генерация карты маршрута: обучение, развилки, типы точек, рост сложности |
| `biomes-mechanics` | биомы: огненный шторм, гонка со временем, грозы; новые биомы |
| `health-damage` | здоровье, урон, неуязвимость, лечение, смерть, предупреждения об атаках |
| `abilities-progression` | ветки Мощь / Ловкость / Мистика, способности, таланты, баланс |
| `procgen-levels` | процедурная сборка уровней из блоков |
| `traversal-validation` | проверка, что каждый уровень и карта проходимы; бот; массовые прогоны seed |
| `art-direction-stylized` | стиль, формы, палитры, рисованные текстуры, читаемость |
| `shaders-vfx` | шейдеры URP (мультяшный свет, контур, подсветка края), эффекты |
| `characters-animation` | герой, скелет, анимации, облики веток |
| `game-audio` | микшер Unity, звуки, адаптивная музыка биомов |
| `unity-architecture` | структура проекта, сборки, данные, детерминизм, производительность, тесты из командной строки |

Плагин **Unity** (официальный) прописан в `.claude/settings.json` — Claude Code предложит установить его при открытии этой папки.

## Главные правила

1. Любой уровень и любая карта проходимы **базовыми движениями** без способностей. Способности дают короткий путь или бонус, но никогда не обязательны.
2. Каждая угроза предупреждает заранее (≥ 0.8 с) и читается формой, а не только цветом.
3. Симуляция детерминирована: свой фиксированный шаг 120 Гц, генерация только от seed, без `UnityEngine.Random` и `Time.time` в логике.
4. Генератор не выпускает уровень, который не прошёл проверку (`traversal-validation`).
5. Цель: 60 FPS на телефоне среднего уровня 2021 года, 120+ FPS на ПК.
6. Интерфейс на русском, тексты короткие.
7. Claude работает с кодом и данными (C#, ScriptableObject, JSON). Сцены и префабы держим минимальными и собираем кодом или данными: правка YAML сцен вручную ненадёжна.
